# Repository agent bootstrap

Đọc [AGENT.md](AGENT.md) và [MEMORY.md](MEMORY.md), sau đó thực hiện selective context loading theo `AGENT.md`. File này là bootstrap cho công cụ tự đọc `AGENTS.md`; **`@AGENT.md` là entry point duy nhất người dùng cần gọi**. Không load toàn bộ context/history mặc định.
